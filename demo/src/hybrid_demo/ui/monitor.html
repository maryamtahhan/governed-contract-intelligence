What these numbers mean

Concurrency is how many requests the benchmark sent at once. Output tok/s is how many tokens the pool wrote per second across all of them. TTFT is the wait before the first token arrives; TPOT is the delay between tokens once writing starts. p50 is the middle request and p95 is the slow tail — one request in twenty is worse than the p95.

The sweep measures this endpoint's own throughput. It is not the pipeline's end-to-end time: a full run makes several calls per document (classify, four extracts, risk), so the run totals in the section above describe different work and do not divide by these rates.
